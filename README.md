# 帧间 · Windows 电脑接入包

让自己的 Windows 制作电脑连接协作网站。朋友在网站的项目对话里提需求、上传文件；本机 Codex 处理后把回复和项目文件传回，之后可以继续提修改意见。

网站：[项目协作](https://projects.zuichenji.cn/projects) · [下载接入包](https://github.com/kaqzsd/frame-studio-windows/releases/tag/windows-connect-2026.11.04)

## 第一次使用

1. 站主在「电脑接入与邀请」给你发一份勾选“允许他接入自己的电脑并邀请朋友”的邀请。已有账号也能接受新邀请，或由站主在「协作成员」开通电脑主人权限。
2. 登录网站，打开「我的电脑与朋友」，填写电脑名称，点击「添加我的电脑」。
3. 在自己的 Windows 下载并解压 ZIP，双击 **00-connect.cmd**。安装向导检查 Python 和官方 Codex CLI；需要下载安装依赖时请保持网络畅通。
4. 网站点击「生成电脑连接码」，把 10 分钟有效的代码粘贴到本机向导。网站地址默认已填好。
5. 按向导在 OpenAI 官方页面登录本人 ChatGPT 订阅。无需 API Key；不会把登录信息交给网站。
6. 检查通过后选择开始接单。网站显示「在线接单中」才表示电脑正在处理网站任务。

以后双击 **05-start.cmd** 接单，**04-check.cmd** 只检查连接，不消耗模型调用。第一次配置仍需本人填写连接码和完成官方登录；不是零操作远程安装。

## 给自己的朋友使用

在「我的电脑与朋友」选择自己的电脑，填写邀请备注和每天最多制作轮次，点击「生成专用邀请」。把邀请链接发给朋友，**不要发电脑连接码**。

朋友注册或使用已有账号接受邀请，点击「新建项目」，选择获准的处理电脑。在对话框发送文字、添加文件，等待结果；要修改时继续在同一个项目对话中发送。

电脑主人只管理自己的电脑与分享，不是全站管理员。朋友可以接受多位电脑主人的邀请，创建项目时选其中一台。停止其中一份分享不会关闭其余分享。已开始制作的项目保持原电脑，避免混用项目记忆。

## 状态怎么看

| 网站状态 | 下一步 |
| --- | --- |
| 还没完成接入 | 打开 00-connect.cmd，填写网站生成的连接码 |
| 等待本机订阅登录 | 在本机完成或更新官方 ChatGPT 登录 |
| 已连接，尚未接单 | 双击 05-start.cmd |
| 在线接单中 | 可以在项目对话里发需求 |
| 主人已暂停接单 | 主人在网站恢复该电脑接单 |
| 接单窗口已停止 | 双击 05-start.cmd 并保持窗口打开 |
| 暂时联系不上制作端 | 检查电脑网络、现有系统代理和接单窗口 |

只打开 ChatGPT 或 Codex 桌面应用不会自动接收本站任务。网页显示的是制作端心跳，不能远程判断电脑电源状态。

## 环境和边界

- Windows 10/11 原生运行，无 WSL。当前实测是 Windows 10 x64；Windows 11、ARM64 和每种全新电脑环境仍需各自验证。
- 使用官方 Codex 客户端的 ChatGPT 登录，模型使用计入登录账号适用的订阅限制；不配置 API Key、不自动转 API 付费。网站每日轮次是本网站任务计数，不代表 Plus 剩余额度或官方刷新时间。
- 接单窗口保持打开就持续接单，每 5 秒查询；关闭窗口停止。不开机自启、不安装系统服务。
- 专用登录、工作目录和项目记忆位于 `%LOCALAPPDATA%\FrameStudioWorker`。程序不读取个人 Codex 记忆。但直接执行模式没有操作系统沙箱，任务仍可能访问本机可访问的文件和网络，只邀请信任的人。
- Python 至少 3.12；先检查已有安装，缺少时尝试官方 winget 安装入口。没有 winget 的旧系统需要先手动安装 Python。官方 CLI 缺少或不兼容时下载固定版本并校验 SHA-512。
- 安装依赖和网站连接使用 HTTPS。安装器只在自己的进程内设置直连，不改变系统代理；受限网络可能需先解决连通性。
- ZIP 是明确文件清单打包的程序源码和说明，不含账号、连接凭据、个人记忆、测试报告或项目文件。公开下载后请对照 SHA256SUMS.txt。
- 这是技术上的本机任务转发，不代表 OpenAI 对订阅额度转供、账号共享或商业代理作出授权。使用范围仍以账号适用条款为准。

## 版本和参考

`windows-connect-2026.11.04` 修复独立 CLI 没有使用 Windows 系统代理的问题，登录和制作统一使用既有系统代理，不修改系统设置。本次系列版本新增电脑主人权限、临时配对、专属朋友邀请、每天轮次限制和准确在线状态。参考 [Sub2API](https://github.com/Wei-Shaw/sub2api) 的分组和访问范围设计，本站独立实现，不部署账号池或转发 OpenAI 登录凭据。
