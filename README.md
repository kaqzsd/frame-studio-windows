# 帧间 · Windows 中文连接助手

[下载最新中文图形版](https://github.com/kaqzsd/frame-studio-windows/releases/latest/download/frame-studio-windows-gui.zip)

帧间 · ChatGPT 连接助手（中文图形版）

适用于 Windows 10/11 x64。解压完整 ZIP，普通双击「帧间连接助手.exe」。
旧 00-connect.cmd 也会打开同一个中文窗口，不再要求在黑色命令行中输入。

第一次连接
1. 网站「电脑接入与邀请」先添加自己的电脑，再生成电脑连接码。
2. 打开助手，先点击「安装 / 修复环境」。如未安装 Python，按中文提示到官方下载并安装 Python 3.12 或更新版本，再返回助手。
3. 填「电脑名」，粘贴「电脑连接码」，网站地址默认已经填好。
4. 点击「连接网站」。助手会完成配对、检查专用 ChatGPT 登录，再检查连接。
5. 如需要登录，窗口会显示一次性代码；点击「打开官方登录页」，用本人的 ChatGPT 账号授权。不要把 ChatGPT 密码填到本工具或协作网站。
6. 检查通过后点击「开始接单」，网站显示「ChatGPT 在线」。朋友的需求和修改会自动回传。

每天使用
普通打开「帧间连接助手.exe」，点击「开始接单」即可。保持窗口打开、电脑开机联网。
点击「停止接单」会停止领取新需求，等当前任务完成后停止。关闭窗口也会先确认停止；没有开机自启。
「检查连接」不调用模型；「离线自检」不连接网站、不消耗订阅。

如安装提示权限问题，可右键「安装环境（右键管理员运行）.cmd」以管理员身份安装，使用当前 Windows 账户。
安装后关闭管理员窗口，再普通打开助手。助手不允许以管理员身份执行朋友的需求。

给朋友使用
网站生成邀请注册链接，朋友注册后，在「批准使用用户」批准使用这台电脑。
不要把电脑连接码发给提交需求的朋友。朋友用自己的网站账号聊天、上传文件和选择模型。

连接说明
电脑名会在配对时同步到网站。连接码 10 分钟有效，失效后到网站重新生成。
清空网站历史或撤销旧电脑后，需要填写新连接码重新配对；本机已有的专用 ChatGPT 登录可以复用。
通用的是整个安装包，不能只复制测试机的桌面快捷方式或单个 CMD 文件。
源码包含 ConnectionAssistant.cs，可用 Windows 自带 .NET Framework C# 编译器审查和构建。

数据边界
专用登录、连接和项目工作目录保存在 %LOCALAPPDATA%\FrameStudioWorker，不上传 ChatGPT 登录、不改个人 Codex 记忆。
网站管理员无法通过网站接口查看别人对话；执行任务的电脑需要处理任务内容，这不是端到端加密。
原生 Windows 直接执行，没有 WSL 或操作系统沙箱，只批准信任的人。
不使用 API Key、不自动转 API 付费；网络中断时保留任务记录，不重复执行未知状态的任务。
